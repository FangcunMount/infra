## 可用性代价与处置边界

若原生回查耗尽或存在矛盾证据，对应 owner 持续拒绝新写；Checker 和读取保留。已提交业务可能仍待消息投递，不能把封闭保护描述为已经恢复投递。未具名查清原库事实、物理消息和真实确认之前不解除，不承诺恢复时长。

后续处理可能需要人工排障和独立审核的修复镜像，因此极端故障的恢复速度较慢。不得用重新执行业务/模型、换事件ID、自动切回NSQ、伪造audit或旧备份覆盖当前事实来恢复可用性。
