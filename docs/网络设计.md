# 基础设施网络设计

## 网络架构

本项目采用**单一网络**设计，所有服务统一使用 `infra-network` 进行通信。

### 网络: infra-network

- **用途**: 所有基础设施服务的内部通信网络
- **驱动**: bridge
- **子网**: `172.20.0.0/16`
- **网关**: `172.20.0.1`
- **MTU**: 1500 (可配置)
- **ICC**: 启用（允许容器间通信）
- **标签**:
  - `infra.network=backend`
  - `infra.purpose=service-communication`

## 连接的服务

所有基础设施服务都连接到 `infra-network`:

- **Nginx** - Web 服务器和反向代理
- **MySQL** - 关系型数据库
- **Redis** - 缓存和会话存储
- **MongoDB** - 文档数据库
- **Kafka** - 消息队列
- **NSQ** - 轻量级消息队列
- **Jenkins** - CI/CD 服务器

## 端口映射

服务通过宿主机端口映射对外暴露：

| 服务 | 内部端口 | 外部端口 | 说明 |
|------|---------|---------|------|
| Nginx | 80, 443 | 80, 443 | HTTP/HTTPS |
| MySQL | 3306 | 3306 | 数据库连接 |
| Redis | 6379 | 6379 | 缓存连接 |
| MongoDB | 27017 | 27017 | 文档数据库 |
| Kafka | 9092 | 9092 | 消息队列 |
| NSQ | 4150-4171 | 4150-4171 | NSQ 各组件端口 |
| Jenkins | 8080, 50000 | 8080, 50000 | Web UI 和 Agent |

## 网络管理命令

### 初始化网络
```bash
make init              # 完整初始化（网络+卷）
make network-init      # 仅初始化网络
```

### 查看状态
```bash
make network-status    # 查看网络状态
make network-list      # 列出所有网络
```

### 重置网络
```bash
make network-reset     # 删除并重建网络
```

### 检查网络详情
```bash
make network-inspect NAME=infra-network
```

## 设计说明

### 为什么使用单一网络？

1. **简化管理**: 只需管理一个网络，减少复杂性
2. **灵活性**: 所有服务可以相互通信，便于服务发现和调用
3. **安全性**: 通过 Docker 内置的网络隔离已足够安全
4. **性能**: 减少网络层数，提高通信效率

### 安全考虑

- 网络与宿主机网络隔离
- 服务间通信通过 Docker 内部网络
- 对外暴露的端口通过宿主机防火墙控制
- 敏感服务（如数据库）可以不映射外部端口

## 环境变量配置

可以通过环境变量自定义网络配置：

```bash
# 自定义子网
INFRA_BACKEND_SUBNET=10.10.0.0/16 make init

# 自定义网关
INFRA_BACKEND_GATEWAY=10.10.0.1 make init

# 自定义 MTU
INFRA_NETWORK_MTU=1450 make init
```

## 故障排查

### 网络无法创建
```bash
# 检查是否有网络冲突
docker network ls

# 检查子网是否被占用
docker network inspect bridge
```

### 服务无法通信
```bash
# 测试网络连通性
make network-status

# 查看服务网络配置
docker inspect <service_name> | grep -A 10 Networks
```

### 网络性能问题
```bash
# 检查 MTU 设置
docker network inspect infra-network | grep -i mtu

# 调整 MTU
INFRA_NETWORK_MTU=1450 make network-reset
```

## 迁移说明

如果之前使用了 `infra-frontend` 网络，需要进行迁移：

```bash
# 1. 停止所有服务
make down

# 2. 删除旧网络（如果存在）
docker network rm infra-frontend 2>/dev/null || true

# 3. 重置基础设施
make reset

# 4. 重新启动服务
make up
```
